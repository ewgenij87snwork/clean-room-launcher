# Security policy

## Supported versions

TaskSeal has not published a supported release yet. Security support begins
only for versions listed in a future release table in this file.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for the TaskSeal repository. Do
not open a public issue containing exploit details, credentials, private paths
or user context. If private vulnerability reporting is unavailable, wait for a
verified maintainer contact to be published in the repository rather than
sending sensitive material to an unverified address.

TaskSeal will never request credentials, provider tokens, transcripts or a copy
of an unrestricted home directory for triage.
