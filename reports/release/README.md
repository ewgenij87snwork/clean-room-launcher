# Release evidence

Files in this directory are dated release/audit evidence snapshots.

They record what was true for the candidate and timestamp named inside each
file. They are not automatically the current product, repository, namespace,
security-reporting, or support state.

For current public behavior and support claims, use:

- `README.md`
- `SECURITY.md`
- `docs/limitations.md`
- the current GitHub release

Do not rewrite historical evidence in place to make it match a later release.
