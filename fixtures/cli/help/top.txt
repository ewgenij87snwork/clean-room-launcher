

Clean Room Launcher v0.2.0
Launch Codex or Claude Code without
unrelated global instructions and skills.

Launch example:
clroom codex --skill-set=any-my-skill,@any-my-skill-set --approve-for-me

Usage
  clroom codex [CODEX_ARGS...] Qualified interactive Codex
  clroom codex exec [CODEX_ARGS...] Qualified non-interactive Codex exec
  clroom claude [CLAUDE_ARGS...] Launch Claude Code
  Provider options: repeat --pass-env=NAME to admit exact existing environment
  names. Drop-in commands: clroom-codex and clroom-claude.
  clroom doctor --root .     Check installation

Skill sets
  /tmp/clroom-help-config/clroom/skill-sets.yaml
  Open file and create skill groups and reuse them by name, such as
  @any-my-skill-set.
